# NovaStore Web Yönetim Paneli

## Proje Hakkında
Bu proje, TNC Group Staj Haftası kapsamında geliştirilmiş, e-ticaret siteleri için React tabanlı bir ürün yönetim panelidir. Proje içerisinde ürün ekleme, listeleme, silme ve güncelleme (CRUD) işlemleri JavaScript kullanılarak yapılmıştır.

## Canlı Yayın (Live Demo)
Projeyi canlı olarak incelemek için:
👉 **[NovaStore Yönetim Paneli (Netlify)](https://jolly-tarsier-d50457.netlify.app/)**

## Kullanılan Teknolojiler
- React (Hooks, Components, Routing)
- Vanilla CSS
- LocalStorage (Veri Kalıcılığı)

## Kurulum ve Çalıştırma
Projeyi yerel bilgisayarınızda çalıştırmak için:

1. Projeyi klonlayın:
   ```bash
   git clone https://github.com/Mrtuz1/novastore-web.git
   ```
2. Gerekli kütüphaneleri yükleyin:
   ```bash
   npm install
   ```
3. Uygulamayı başlatın:
   ```bash
   npm start
   ```
Uygulama `http://localhost:3000` adresinde çalışacaktır.
